# Stocking records

One file per lake id, `stocking/<id>.json`: the province's own stocking history
for that water (Ontario MNRF Historical Fish Stocking Data 1905-2015 and Fish
Stocking Data for Recreational Purposes 2016-present, Open Government Licence -
Ontario), joined by the lake's provincial waterbody id or, where the pack has
none, by name within 8 km of the lake centre; each file says which. A lake with
no record carries an honest-empty file. Packs built after November 2026 carry the
same file inside as `config/stocking.json`; the app reads these sidecars for
older packs and caches them. Regenerated by `work/stocking_on.py --app` in the
pipeline workspace.
